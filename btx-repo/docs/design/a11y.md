# BTX Accessibility & Localisation

## Targets

| Surface | Target |
|---|---|
| Citizen wallet | **WCAG 2.2 AA**; **AAA** on consent / revoke screens |
| Consent UI | **WCAG 2.2 AAA** (contrast, language level, error prevention) |
| Operator console | WCAG 2.2 AA + keyboard-complete |
| Auditor dashboard | WCAG 2.2 AA + keyboard-complete + screen-reader narratable evidence pack |
| Public portal | WCAG 2.2 AA |
| Member portal | WCAG 2.2 AA |

Track standards: WCAG 2.2, EN 301 549, India Web GIGW 3.0, ARIA 1.2, APCA where applicable.

## Non-negotiable rules

1. **Keyboard-complete**: every operator / auditor flow finishable with keyboard only; visible focus ring everywhere (`color.border.focus` token).
2. **Screen-reader narratable**: every interactive control has accessible name + role; every audit event renders as readable prose (`On 16 May 2026 at 09:12 IST, …`).
3. **Reduced motion**: respect `prefers-reduced-motion`; no essential information conveyed by motion alone.
4. **Colour is never the only signal**: pair with icon + text.
5. **Error prevention** on consent / destructive flows: confirm with summary of consequences and a way back. (WCAG 3.3.4 / 3.3.6)
6. **Time limits**: no implicit timeouts on consent screens; if a session must expire, warn ≥ 20 s before and allow extension. (WCAG 2.2.1)
7. **Plain language**: reading level ≤ class 8 for citizen-facing; ≤ class 10 for member-facing.
8. **Multilingual**: every citizen-facing string has Hindi + English; expandable to 12 scheduled languages.
9. **Right-to-left readiness**: Urdu, Sindhi — layouts mirror cleanly. Test with `dir="rtl"`.
10. **Numerals**: support Devanagari, Tamil, Bengali, etc. digits where citizens prefer them; never in operator console.

## Low-end device budget (citizen wallet)

| Budget | Target |
|---|---|
| Cold start (4G) | ≤ 2.0 s on Moto G4-class device |
| Bundle (initial) | ≤ 120 KB gzipped JS, ≤ 50 KB CSS |
| Time-to-interactive on 3G | ≤ 5 s |
| RAM ceiling | works on 2 GB devices, no crashes |
| Offline | consent history viewable offline (last 30 d) |
| Storage | ≤ 5 MB on device |

CI enforces with Lighthouse mobile (throttled 3G, Moto G4 CPU), bundle-size budget gates.

## Annotation contract (Figma → code)

Every screen in Figma carries an `a11y.json` companion (also exportable via Figma plugin):

```json
{
  "frame": "consent-grant--default",
  "landmarks": [
    { "role": "main",   "label": "Grant consent" },
    { "role": "complementary", "label": "What this means" }
  ],
  "headings": [
    { "level": 1, "text": "Share income certificate?" }
  ],
  "controls": [
    { "id": "btn-grant",   "role": "button", "name": "Share for scholarship verification",
      "keyboard": "Enter / Space", "focus_order": 4, "confirms": true },
    { "id": "btn-cancel",  "role": "button", "name": "Do not share",
      "keyboard": "Enter / Space", "focus_order": 5, "is_default_safe": true }
  ],
  "live_regions": [
    { "id": "share-summary", "politeness": "polite" }
  ],
  "language": "hi-IN",
  "reading_level": 7
}
```

CI: `tools/a11y-annotations-validate` checks every Figma frame in scope has a matching annotation file, no orphans, every interactive node mapped.

## Content rules

- **Forbidden** in citizen UI: legal jargon ("data fiduciary"), passive voice on consent verbs, double negatives, all-caps for emphasis, abbreviations without expansion on first use.
- **Required** on every consent moment: who's asking, what's shared, *for what purpose*, retention window, revoke link, evidence link.
- **Numbers**: dates as `16 May 2026` (citizen) or `2026-05-16T09:12:00+05:30` (operator/auditor).
- **Time-zone**: always IST for citizens; UTC + IST for operator/auditor.

## Testing matrix

| What | Tool | Gate |
|---|---|---|
| Static a11y (component) | axe-core in Jest + Storybook | 0 violations |
| Static a11y (page) | axe-core in Playwright | 0 violations (AA), warn (AAA) |
| Contrast at token level | `tools/tokens-a11y-check` | 0 failures |
| Reading level | `tools/reading-level-check` (Flesch–Kincaid for English, equivalent for Hindi) | ≤ target per surface |
| RTL render | Playwright with `dir="rtl"` | snapshot matches |
| Reduced motion | Playwright with `prefers-reduced-motion` | no animation |
| Real screen reader | Manual: NVDA + Chrome, VoiceOver + Safari, TalkBack + Chrome Android | pass for P0 flows |
| Real low-end device | Manual + WebPageTest Moto G4 / 3G | meets budget |
| Real users with disabilities | P-25 usability test | included in panel |

## Localisation pipeline

1. Source strings in `en-IN` and `hi-IN` authored alongside design.
2. ICU MessageFormat with explicit plurals and gender where relevant.
3. Crowdin / Lokalise sync; translators see screenshot + context.
4. Pseudo-localisation build (`xx-AC`) in CI catches truncation and concatenation bugs.
5. No string lookup at render-time without a fallback — missing translation MUST fall back gracefully and log a metric.

## Failure to meet target

- A11y CI is **blocking** on AA. AAA findings are tracked but non-blocking unless on a consent / revoke / incident screen — there they are blocking.
- Performance budget is blocking for citizen wallet — regression > 10% reverts the PR.
