## Wrong vs right

**Wrong** — hard-code colours and spacing
```tsx
<button className="bg-[#1F5AA8] text-white px-4 py-2 rounded-md">Share</button>
```

**Right** — use the token preset
```tsx
<Button intent="primary" size="md" onClick={onGrant}
        data-event="consent.grant.submit" data-testid="btn-grant">
  {t("btn_grant")}
</Button>
```

**Wrong** — log the consent payload "for debugging"
```ts
analytics.track("consent.grant.submit", { payload: req })   // PII leak
```

**Right** — IDs and hashes only
```ts
analytics.track("consent.grant.submit", { txn_id, policy_version, kid })
```

**Wrong** — drift from Figma without re-locking
```md
> "I tweaked the design and the code together"
```
**Right** — pin Figma version; any change → re-run P-23 first
