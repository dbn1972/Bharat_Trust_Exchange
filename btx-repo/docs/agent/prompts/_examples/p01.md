## Wrong vs right

**Wrong** — handler does the authorisation
```go
func (h *Handler) Grant(w http.ResponseWriter, r *http.Request) {
    if r.Header.Get("X-Role") != "steward" { http.Error(w, "forbidden", 403); return }
    h.svc.Grant(r.Context(), ...)
}
```

**Right** — delegate to PurposeGuard with fail-closed obligations
```go
func (h *Handler) Grant(w http.ResponseWriter, r *http.Request) {
    dec, err := h.pdp.Decide(r.Context(), pdp.RequestFromHTTP(r))
    if err != nil { writeProblem(w, btxerr.AuthzPdpUnavailable); return }
    if dec.Decision != pdp.Allow { writeProblem(w, btxerr.AuthzDenied(dec.Reasons)); return }
    res, err := h.svc.Grant(r.Context(), dto.FromHTTP(r), dec.Obligations)
    ...
}
```
