## Wrong vs right

**Wrong** — accept direct DB write because "the queue adds complexity"
**Right** — consent/audit paths require queue + idempotency + DLQ. No exceptions without an ADR.

**Wrong** — claim multi-region readiness based on stateless services
**Right** — stateful services must have RPO/RTO documented and a tested failover playbook
