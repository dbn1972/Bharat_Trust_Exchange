## Wrong vs right

**Wrong** — leaks DB error to caller, no audit
```go
if err := repo.Save(ctx, v); err != nil { return err }   // 500 with raw pg error
```

**Right** — typed BTX error, audit emit
```go
if err := repo.Save(ctx, v); err != nil {
    return btxerr.Wrap("BTX-DATA-001", err)
}
audit.MustEmit(ctx, ev.CatalogueVersionPublished(v.ID, v.MemberID, dec.PolicyVersion))
```
