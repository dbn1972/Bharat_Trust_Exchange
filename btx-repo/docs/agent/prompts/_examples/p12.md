## Wrong vs right

**Wrong** — sign images, skip SBOM
**Right** — every image: cosign signed + SBOM (syft) + SLSA L3 attestation; bundle TUF-signed

## Executable acceptance

```bash
for c in aws azure gcp onprem; do make certify CLOUD=$c; done                  # exit 0 each
tools/sign-all-images v1.7.0                                                    # all images signed + SBOM + SLSA
tools/policy-bundle-verify                                                      # TUF roles verify
tools/evidence-pack assemble v1.7.0
cosign sign-blob --yes evidence/v1.7.0/pack.tar.gz \
  --output-signature evidence/v1.7.0/pack.sig                                  # exit 0
test -f release-notes/v1.7.0-canary.md                                          # exists with rollback rules
```
