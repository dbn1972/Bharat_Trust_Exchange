# Example for P-35

## Scenario

An admin plugin panel component exists in `apps/portal/src/features/admin`, but the portal has no app shell, route mounting, or secure runtime auth pattern. The task is to turn that component into a real operator surface.

## Wrong approach

```diff
- export const AdminPluginSettingsPage = () => <MessageBrokerPluginPanel ... />
+ // component exists but nothing imports or renders it
```

This leaves the feature as dead code.

## Right approach

```diff
+ // apps/portal/src/App.tsx
+ import { AdminPluginSettingsPage } from './features/admin';
+
+ export function App() {
+   return <AdminPluginSettingsPage apiBaseUrl={import.meta.env.VITE_API_BASE_URL} />;
+ }
```

Then add a secure auth proxy or server-side token handling so the browser is not given raw privileged secrets.

## Expected artefacts

- runnable `apps/portal` package with entrypoint
- route/page mounting `AdminPluginSettingsPage`
- save flow tested end-to-end against `/v1/admin/plugins/message-broker`
- evidence logs or screenshots under `evidence/portal/`
