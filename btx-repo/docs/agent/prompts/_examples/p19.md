## Wrong vs right

**Wrong** — tests mock the service under test
```go
mockSvc := mocks.NewServiceCatalogue(t)
mockSvc.On("Publish", ...).Return(nil)        // tests the mock, not the code
```

**Right** — exercise real code paths; mock only adapters
```go
svc := catalogue.New(mockRepo, mockKafka)      // real svc, fake deps
err := svc.Publish(ctx, validVersion)
```

**Wrong** — behaviour change ("fix" a bug while backfilling)
**Right** — open a separate PR for the behaviour change; backfill PR is tests only
