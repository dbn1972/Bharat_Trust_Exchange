## Wrong vs right

**Wrong** — log request body for "debug"
```go
log.Info("shaping response", "body", string(payload))   // PII leak
```

**Right** — log only IDs, decision and obligations
```go
log.Info("shape", "txn_id", txn, "obligation", dec.Obligations[0].Kind,
         "kid", signer.Kid())
```

**Wrong** — synchronous PDP call inside Envoy filter path
**Right** — ext_authz to OPA sidecar with 200 ms timeout, fail-closed
