## Journey (excerpt — Mermaid)

```mermaid
sequenceDiagram
  participant C as Citizen
  participant W as Consent UI
  participant T as Trust Node
  C->>W: Open consent link from Scholarship Portal
  W->>C: Show: who, what (exact fields), purpose, retention, revoke link
  Note over W: consent moment — no animation, no auto-advance
  C->>W: Press "Share for scholarship verification" (or Enter on Cancel as safe default)
  W->>T: POST /v1/consents (minimised)
  T-->>W: 201 (txn_id, policy_version, kid)
  W->>C: Success — link to evidence + revoke
  alt error
    T-->>W: 5xx
    W->>C: "We couldn't share. Nothing was shared. Try again."
  end
```

## Wrong vs right

**Wrong** — "Share details" generic label
**Right** — exact fields visible: "yes/no over ₹2.5L threshold"

**Wrong** — auto-advance to success after 2 s of hover
**Right** — explicit press; no timer; Cancel is the keyboard default
