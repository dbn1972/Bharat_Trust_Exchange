## Wrong vs right

**Wrong** — caller chooses URL
```go
url := req.URL                                  // arbitrary backend
resp, _ := http.Get(url)
```

**Right** — allowlisted host + typed client
```go
client := rcmsclient.New(cfg.BaseURL, cfg.MTLS)   // mTLS + allowlisted host
resp, err := client.GetLandRecord(ctx, req.Khasra)
if err != nil { return btxerr.Wrap("BTX-AVAIL-001", err) }
```

**Wrong** — minimise inside connector (do it in Shaper)
**Right** — return raw source response; Shaper applies obligations
