## Interaction spec (excerpt)

| Frame | Trigger | Result | Side effect | Keyboard |
|---|---|---|---|---|
| consent-grant--default | press `btn-grant` | optimistic → POST /v1/consents | audit `consent.granted` | `Enter` on `btn-cancel` (focus default) |
| consent-grant--default | press `btn-cancel` | close; return `decision=deny` | audit `consent.denied` | `Esc` |
| consent-grant--loading | network slow | skeleton on summary; disable buttons | none | focus trapped |
| consent-grant--error   | submit fails | inline error + retry; nothing shared | metric `share_error` | `Enter` retries |

## Wrong vs right

**Wrong** — animate the Share button to attract attention
**Right** — static; Cancel is the default; symmetrical visual weight

**Wrong** — English-only copy on rural panel
**Right** — Hindi + English; reading level ≤ 7; pseudo-locale passes
