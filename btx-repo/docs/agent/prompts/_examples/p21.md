## Wrong vs right

**Wrong** — coin a one-off colour on a single screen
```json
"consent-ui.color.minimised.bg": { "$value": "#EFF6FF" }
```

**Right** — surface token references semantic
```json
"consent-ui.color.minimised.bg":     { "$value": "{color.feedback.info.bg}" },
"consent-ui.color.minimised.fg":     { "$value": "{color.feedback.info.fg}" },
"consent-ui.color.minimised.border": { "$value": "{color.feedback.info.border}" }
```

**Wrong** — rename `color.action.primary` → `color.cta.primary` as a patch
**Right** — major bump + migration row in `CHANGELOG-design.md`
