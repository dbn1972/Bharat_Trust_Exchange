# P-06 — Example

## Filled invocation

```yaml
inputs:
  EVENT: exchange.decision
  TOPIC: btx.audit.v1
  TRIGGER: "after PurposeGuard returns a decision and obligations"
  HASHED_FIELDS: [citizen_subject_ref]
```

## Wrong vs right

**Wrong** — embed body & PII
```go
audit.Emit(ev.ExchangeDecision(WithBody(req.RawBody), WithAadhaar(req.Aadhaar)))
```

**Right** — IDs and hashes only
```go
audit.MustEmit(ctx, ev.ExchangeDecision(
    ev.TxnID(txn), ev.MemberID(req.MemberID),
    ev.ServiceID(req.ServiceID), ev.PurposeCode(req.Purpose),
    ev.Decision(dec.Decision), ev.Obligations(dec.Obligations),
    ev.CitizenRefHash(sha256Hex(req.Subject)),
    ev.Kid(signer.Kid()), ev.PolicyVersion(dec.PolicyVersion),
))
```

**Wrong** — silent drop
```go
_ = producer.Publish(ev)        // no error handling
```

**Right** — fail-closed alert
```go
if err := producer.Publish(ctx, ev); err != nil {
    metrics.AuditEmitFailures.Inc()
    log.Error("audit emit failed", "err", err)
    return btxerr.Wrap("BTX-AUDIT-001", err)
}
```
