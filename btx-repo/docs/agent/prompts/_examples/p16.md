## Sample review comment

```
## Summary
PR-1234 adds catalogue version publish endpoint. Scope is right-sized (8 files, 612 LOC).
Architecture conformance OK (ADR-001, ADR-014). Tests and audit event present.

## Blocking
- [ ] services/service-catalogue/internal/transport/http/handler.go:88
      Authorisation done in handler. MUST delegate to PurposeGuard (ADR-005).
- [ ] api/openapi.yaml: missing 4xx schemas for BTX-AUTHZ-001, BTX-VALIDATION-002.

## Non-blocking
- nit: extract repo error mapping to pkg/btxerr/pg.go.
- consider adding contract test for the new event (CT-008).

## Acknowledgements

- Audit emit follows pkg/audit conventions.
```

## Wrong vs right

**Wrong** — "LGTM, will address comments in follow-up"
**Right** — request changes; do not approve until blockers resolved
