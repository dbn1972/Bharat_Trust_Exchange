# P-07 — Example

## Filled invocation

```yaml
inputs:
  CLOUD: oci

```

## Wrong vs right

**Wrong** — cloud SDK leaks into domain
```go
// services/signer/internal/domain/sign.go
import "github.com/oracle/oci-go-sdk/kms"
```

**Right** — domain depends on interface; OCI lives in `pkg/adapter/kms/oci.go`
```go
// services/signer/internal/domain/sign.go
import "btx/pkg/adapter/kms"

func (s *Signer) Sign(b []byte) ([]byte, error) { return s.kms.Sign(s.kid, b) }
```
