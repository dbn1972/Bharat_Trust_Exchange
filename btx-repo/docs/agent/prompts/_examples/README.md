# Prompt examples

> One file per prompt (`p01.md` … `p20.md`). Each carries:
>
> 1. A **fully filled invocation** (placeholders replaced) you could paste straight into Claude Code.
> 2. **Wrong vs right** mini-diffs for the most common failure modes specific to that prompt.
> 3. **Executable acceptance** commands the agent should run, with thresholds.
> 4. The **self-score block** the agent must emit before opening the PR.
>
> Updates to a prompt MUST update its example file (the linter enforces co-existence; reviewers enforce co-correctness).
